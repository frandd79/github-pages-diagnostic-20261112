Uso personal de datos

Política de privacidad

Esta política describe el uso previsto de Discovery Lab Nova — Solo lectura, un cliente personal operado por el propio titular de la cuenta dedicada. No se ofrece registro ni acceso a terceros. La conexión permanece pendiente de autorización y validación.

Qué datos se consultan y para qué

El cliente utiliza rclone y las API de Google para consultar informes de Discovery Lab de una carpeta privada de intercambio: contenido de los documentos y metadatos necesarios para identificarlos, verificar su procedencia, permisos, integridad y versiones. Descarga los informes autorizados al mini-PC del titular para su consulta y validación local.

Se solicita exclusivamente drive.readonly. Este permiso no concede escritura, pero su alcance real comprende todos los archivos de Drive accesibles a la cuenta. La carpeta seleccionada es una restricción del programa, no del token.

Almacenamiento y conservación

Los informes descargados y los registros operativos se conservan localmente bajo control del titular. Los registros pueden incluir identificadores, fechas, resultados y hashes de integridad. Las credenciales se guardan por separado, con acceso local restringido, fuera de esta web y del repositorio público.

No se establece un borrado automático por plazo. El titular decide cuándo eliminar las copias locales y sus registros. Si existen copias de seguridad, debe gestionar también su conservación y eliminación; no se promete borrado inmediato de esas copias.

Comunicación y usos excluidos

El circuito de lectura comunica las solicitudes necesarias a Google y devuelve los datos al equipo del titular. No publica los informes ni los envía a GitHub. Este cliente no vende datos, no los utiliza para publicidad y no los envía a proveedores de modelos para entrenamiento o inferencia.

Los datos de Google se utilizarán únicamente para las finalidades aquí descritas, de acuerdo con la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos sus requisitos de uso limitado. Cualquier uso futuro distinto debe revisarse antes de activarse.

Revocación y eliminación

El titular puede retirar el acceso desde las conexiones de su cuenta Google y dejar de ejecutar el cliente. Revocar el acceso impide nuevas lecturas autorizadas, pero no elimina los informes ya descargados. Para eliminarlos debe borrar sus copias locales y revisar las copias de seguridad que conserve.

Esta web informativa

Las páginas no incorporan formularios, analítica, publicidad, JavaScript ni cookies propias. El alojamiento previsto es GitHub Pages. GitHub registra datos técnicos de las visitas, incluida la dirección IP por motivos de seguridad, conforme a su declaración de privacidad. Al seguir un enlace externo se aplican las prácticas del sitio de destino.

Responsable y consultas

El responsable de esta configuración personal es su titular y único usuario. El correo de asistencia se muestra en la configuración de consentimiento de Google. No deben enviarse informes privados, contraseñas ni tokens mediante comentarios públicos del repositorio.
